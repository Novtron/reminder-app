# یادآوری کارهای روزانه — نسخه Rust (Tauri v2)

داشبورد فارسی یادآوری کارهای روزانه، بازنویسی‌شده با Rust و Tauri v2.
رابط کاربری: HTML/CSS/JS ساده، راست‌به‌چپ، فقط تم روشن، سبک شیشهٔ مایع.
داده‌ها در خود دستگاه ذخیره می‌شوند (localStorage).

## امکانات

- افزودن کار با دسته و اولویت
- یادآوری بازه‌ای: مثلاً از ۱۴:۰۰ تا ۰۰:۰۰ هر ۳۰ دقیقه
- یادآور فقط یک‌بار: مثلاً فقط امروز ساعت ۱۵:۰۰
- کلید «تکرار روزانه» برای هر کار
- تیک انجام، پیشرفت روز، نوار هفته، سابقهٔ یادآوری‌ها
- دستیار هوشمند درون‌برنامه‌ای (پیام متنی فارسی را می‌فهمد و پیش‌نویس کار می‌سازد)
- هشدار درون‌برنامه‌ای با صدا و لرزش + تعویق ۱۰ دقیقه‌ای — فقط وقتی برنامه باز است

## بیلد محلی (APK دیباگ)

پیش‌نیاز: Rust stable (۱.۹۹.۱)، JDK 17 (Temurin)، Android SDK
(platform android-35، build-tools 35.0.0، NDK 27.2.12479018،
platform-tools) و Tauri CLI 2 (`npm install -g @tauri-apps/cli@2`).
compileSdk و targetSdk پروژه ۳۵ است (پلتفرم ۳۷ در مخزن گوگل نیست).

```bash
source ~/android-env.sh        # در این VM؛ مسیرهای JAVA_HOME و ANDROID_HOME
export NDK_HOME=$ANDROID_HOME/ndk/27.2.12479018
rustup target add aarch64-linux-android
cd src-tauri
tauri android init             # فقط بار اول؛ gen/android ساخته می‌شود
tauri android build --debug --target aarch64
```

خروجی: `src-tauri/gen/android/app/build/outputs/apk/debug/app-debug.apk`

## وضعیت بیلد — ۲۰۲۶-۱۱-۰۸

APK هنوز ساخته نشده است. مانع: از حدود ۲۳:۰۰ UTC روز ۲۰۲۶-۱۱-۰۷ اینترنت
خروجی این VM قطع شد — پروکسی hatch-egress-proxy:3128 اتصال TCP را قبول
می‌کند ولی به درخواست CONNECT هیچ پاسخی نمی‌دهد؛ هم `curl` و هم
`cargo` و هم Python تایم‌اوت می‌خورند. به همین دلیل `cargo` نتوانست
ایندکس crates.io را بگیرد و هیچ crateای دانلود نشده است (کش رجیستری
خالی است) — پس بیلد آفلاین هم ممکن نیست. چند VM پشت سر هم عوض شدند
و قطعی در همه‌شان ادامه دارد؛ مشکل از سمت هاست است، نه از پروژه.

آنچه آماده است: سورس کامل پروژه + `src-tauri/gen/android` (خروجی
`tauri android init`) + محیط بیلد نصب‌شده روی همین VM. برای ادامه،
کافی است وقتی اینترنت برگشت همان دستور بیلد بالا اجرا شود؛ نیازی به
نصب دوبارهٔ Rust/JDK/SDK نیست. دستور `tauri android build` اول
وابستگی‌های Rust را دانلود می‌کند (چند دقیقه) و بعد Gradle وابستگی‌های
اندروید را می‌گیرد؛ حافظه کم است، پس حتماً با `CARGO_BUILD_JOBS=1`
و Gradle تک‌جابه (در `gradle.properties` تنظیم شده) اجرا شود.

نکته: گذرواژهٔ پروکسی در `~/android-env.sh` در هر اجرا از متغیر محیط
تازه خوانده می‌شود؛ پس بیلد باید در همان نشست شل اجرا شود، نه بعداً.

## بیلد در GitHub Actions

فایل `.github/workflows/android.yml` روی هر push به `main` اجرا می‌شود:
JDK 17 و Rust و Android SDK و NDK 27 را ست‌آپ می‌کند، APK دیباگ را می‌سازد
و آن را به‌عنوان artifact با نام `reminder-app-debug-apk` آپلود می‌کند.
هیچ پوشی از این ماشین انجام نمی‌شود؛ کافی است همین پوشه را به ریپو push کنید.

## محدودیت‌ها

- اعلان وقتی برنامه بسته است نمی‌آید (هشدار فقط درون برنامه، وقتی باز است).
  نوبت‌های ازدست‌رفته در «سابقهٔ یادآوری‌ها» ثبت می‌شوند.
- دستیار هوشمند درون‌برنامه‌ای قانون‌محور است و به اینترنت وصل نیست.
